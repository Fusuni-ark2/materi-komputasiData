2.4 Protokol Transfer: UDP dan TCP

Perbandingan UDP vs TCP

🚀 UDP
  • Connectionless
  • Tidak andal
  • Cepat & ringan
  • Header 8 byte
Cocok untuk:

Video call, Streaming, DNS

🛡️ TCP
  • Connection-oriented
  • Reliable (ada ACK)
  • Flow control
  • Header 20+ byte
Cocok untuk:

Download, Email, Web
